# Volti dei nemici

Metti qui le foto da usare come volti dei nemici. Ogni nemico ne prende una a caso.

**Come caricarle dall'iPad:** su github.com apri questa cartella, poi
**Add file → Upload files**.

## Consigli per le foto
- **Formato**: `.jpg`, `.png` o `.webp`
- **Inquadratura**: viso frontale, ben illuminato, occhi verso l'obiettivo
- **Ritaglio**: meglio un quadrato centrato sul viso, ma non è obbligatorio:
  il gioco ritaglia il centro dell'immagine
- **Peso**: sotto i 300 KB ciascuna (512×512 px bastano e avanzano)
- **Nomi**: semplici, senza spazi (es. `marco.jpg`, `nemico-01.png`)

## Attenzione
Il repository è **pubblico**: chiunque può vedere queste foto. Usa la tua faccia,
quella di amici che ti hanno dato il permesso, oppure volti inventati o generati.
